# Third-party data & assets

The application code is MIT-licensed (see [LICENSE](LICENSE)). It bundles the following third-party data and assets, each under its own terms:

## Airport reference data — OurAirports

`data/reference/airports.csv`, `data/reference/countries.csv`

Snapshot of [OurAirports open data](https://ourairports.com/data/), released by its maintainers into the **public domain**. Refresh from <https://davidmegginson.github.io/ourairports-data/>.

## Airline reference data — OpenFlights

`data/reference/airlines.dat`

Snapshot of the [OpenFlights airline database](https://openflights.org/data.html), available under the **Open Database License (ODbL)**. This notice serves as attribution; if you redistribute a modified airline database, ODbL share-alike terms apply to the data.

## World map — Natural Earth via world-atlas

The offline world map is rendered from the [`world-atlas`](https://github.com/topojson/world-atlas) npm package (TopoJSON of **Natural Earth**, which is public domain).

## Font — Pretendard

The bundled UI font is [Pretendard](https://github.com/orioncactus/pretendard), licensed under the **SIL Open Font License 1.1**.

## Logo & artwork

The paper-plane logo, wordmark, and dashboard hero artwork are original assets generated for this project and are covered by the repository's MIT license.
